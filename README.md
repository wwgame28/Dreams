# TraceZero MVP

PWA-прототип центра управления цифровым следом. Работает как статический сайт и может быть опубликован на GitHub Pages.

## Возможности прототипа
- панель цифрового риска;
- найденные аккаунты и очередь удаления;
- экран проверки утечек;
- интерфейс очистки метаданных;
- тарифы Free / Protect / Concierge;
- установка на домашний экран как PWA.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```
Папка `dist` готова к публикации.

## GitHub Pages
В настройках репозитория подключите GitHub Actions или разместите содержимое `dist` в ветке `gh-pages`.

## Следующий этап
Подключить безопасный backend API:
- Sherlock для поиска собственных профилей по подтверждённому нику;
- каталог удаления на основе JustDeleteMe;
- Have I Been Pwned или XposedOrNot по официальным условиям API;
- локальную очистку EXIF через WebAssembly;
- OAuth для анализа регистрационных писем без хранения паролей;
- оплату через ЮKassa/Stripe.

## Безопасность
Поиск должен выполняться только после подтверждения владения email/телефоном/ником. Нельзя использовать продукт для скрытого поиска третьих лиц.

## Развёртывание на Amvera

Проект подготовлен для Docker-развёртывания. В корне уже находятся `Dockerfile`, `nginx.conf` и `amvera.yml`.

1. Создайте приложение в Amvera и выберите подключение GitHub-репозитория.
2. Подключите репозиторий `wwgame28/Dreams`, ветку `main`.
3. Запустите сборку. Amvera соберёт Vite-приложение и запустит Nginx на порту 80.

Никакие команды запуска вручную указывать не требуется.
