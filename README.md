# TraceZero v3

Новая минимальная версия сервиса самоаудита цифрового следа.

## Возможности
- поиск собственных публичных профилей по нику;
- ссылки на профиль и официальную страницу удаления;
- массовая очередь «Удалить всё найденное»;
- локальное удаление EXIF/GPS из изображений;
- хранение результатов только в браузере.

## Запуск в Amvera
Проект использует Docker и порт 8080. После обновления репозитория выполните полную пересборку проекта.

## Ограничения
Сервис не ищет и не раскрывает данные третьих лиц по телефону, госномеру автомобиля или другим персональным идентификаторам.
